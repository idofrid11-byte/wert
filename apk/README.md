# AetherStream Android APK Release

Welcome to the standalone APK distribution for **AetherStream** — the open media aggregator, Stremio add-on client, and streaming player.

## Included Files
- `AetherStream-v1.0.0.apk`: Ready-to-install Android Application Package.
- `app-debug.apk`: Development debug package.

- **Version:** 1.0.0 (Build 1)

## Installation Instructions (Sideloading)
1. Download or transfer `AetherStream-v1.0.0.apk` to your Android device.
2. Open your device's **Files** or **Downloads** app.
3. Tap on `AetherStream-v1.0.0.apk`.
4. If prompted, toggle **"Allow installation from this source"**.
5. Tap **Install** and launch **AetherStream**.

## Features in this Build
- **Stremio Cinemeta Catalog:** Real-time movies, TV series, and anime metadata.
- **Add-on Hub & Diagnostics:** Official & community add-on manager, custom manifest URLs, live ping latency monitor, and CDN speed tester.
- **Playback Suite:** 4K/1080p stream switcher, aspect ratio toggling (Fit, Fill/Crop, Stretch), sleep timer, and trailer mode.
- **Audio & Subtitle Controls:** Multi-track audio, speech clarity, dialogue boost, audio sync offset, multi-language CC, size, color, background styling, and vertical positioning.
- **Library Hub:** Watchlist tracking, offline downloads manager, and custom curated collections/playlists.
- **Discover Tools:** Instant search, sub-genre filter pills, and "Random Pick / Surprise Me" recommendation generator.
